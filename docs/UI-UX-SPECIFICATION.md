## หน้า 5: Database Configuration (Admin Only)

URL: `/admin/settings/database`

### Form Fields

| Field | Description |
|---|---|
| Connection Name | ชื่อ Connection เช่น `HOSxP RDU Read Only` |
| Database Driver | เช่น `PostgreSQL` |
| Host | IP หรือ Hostname เช่น `192.168.1.100` |
| Port | เช่น `5432` |
| Database Name | ชื่อ Database เช่น `hosxp` |
| Schema | เช่น `public` |
| Username | เช่น `rdu_readonly` |
| Password | แสดงเป็น `********` |
| Charset | เช่น `utf8` |

## Navigation & Routes (คร่าวๆ)

| Route | หน้า | Middleware |
|---|---|---|
| `/login` | หน้า Login | guest |
| `/dashboard` | Overview of every active KPI | auth |
| `/dashboard/kpi/{code}` | KPI Detail | auth |
| `/reports` | ออกรายงาน | auth |
| `/admin/settings/database` | DB Config | auth + admin |
| `/admin/settings/users` | จัดการ User | auth + admin |

---

## Design Style

- Modern Admin UI — Clean, minimal
- รองรับ Responsive Layout (Desktop-first)
- ใช้ Chart.js สำหรับ Line Chart (Trend), Bar Chart (Comparison)
- สีสถานะ: Green (ผ่าน), Red (ไม่ผ่าน), Yellow (ใกล้เป้าหมาย ±5%)
- Sidebar แสดง Badge สีสถานะแต่ละ KPI
- Skeleton loading สำหรับ KPI Cards
