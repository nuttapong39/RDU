## หน้า 1: Overview Dashboard

URL: `/dashboard` (`resources/views/dashboard/index.blade.php`) — ปรับเป็นแบบ minimal 2026-10-17
หลักการ: **สีใช้บอกสถานะอย่างเดียว** (ผ่าน/ใกล้เป้า/ไม่ผ่าน/ไม่มีข้อมูล) ส่วนอื่นเป็นสีเทา ไม่มีส่วนที่ซ้ำข้อมูลของ KPI card

### 1. Hero Card

```
┌──────────────────────────────────────────────────────────────────┐
│ [SVG แคปซูล+✓]  RDU Dashboard                [ปีงบ 2569 ▾][ทั้งปี ▾][รีเฟรช] │
│                การใช้ยาอย่างสมเหตุสมผล (Rational Drug Use) · รพ.เชียงกลาง       │
│                ข้อมูลจาก HOSxP · อัปเดตทุก 1 ชั่วโมง                             │
│ ──────────────────────────────────────────────────────────────── │
│ ● ผ่านเกณฑ์ 9   ● ใกล้เป้าหมาย 0   ● ไม่ผ่านเกณฑ์ 3   ● ไม่มีข้อมูล 0        │
└──────────────────────────────────────────────────────────────────┘
```

- รูปเป็น SVG ฝังในหน้า (ไม่มีไฟล์รูป) สถานะที่เป็น 0 แสดงจาง
- ไม่มีคำทักทาย/เวลาที่เปิดหน้า (เวลาเซิร์ฟเวอร์เป็น UTC และไม่ใช่เวลาที่คำนวณข้อมูล) — ผลคำนวณแคชไม่เกิน 1 ชั่วโมง

### 2. แถบ "ต้องดูก่อน"

```
ต้องดูก่อน  (KPI01 57.5% (เป้า ≤ 40%))  (KPI02 52.2% (เป้า ≤ 40%))  (KPI12 0.1% (เป้า ≤ 0%))
```

- ชิปของ**ทุก** KPI ที่ไม่ผ่านหรือใกล้เป้า (ไม่จำกัดจำนวน) ไม่ผ่านขึ้นก่อน แล้วเรียงตามระยะที่ห่างเป้า (ปรับทิศแล้ว)
- คลิกแล้วไปหน้า KPI นั้น ชิปแดง = ไม่ผ่าน เหลือง = ใกล้เป้า มีป้าย "เคสน้อย · n=X" ถ้าเป็นเคสน้อย
- ถ้าทุกตัวผ่าน ไม่แสดงแถบนี้

### 3. KPI Grid (แบ่งตามหมวด เรียงตามรหัส)

หัวหมวด "หมวดยาปฏิชีวนะ (5 ตัวชี้วัด)" — หมวดที่ไม่มี KPI ที่เปิดใช้งาน (คุณภาพยา) ไม่แสดง
grid 1 / 2 / 3 / 4 คอลัมน์ตามความกว้างจอ

```
┌──────────────────────────────┐
│ [KPI01]            ไม่ผ่านเกณฑ์ │  ← รหัสเป็นชิปสีเทา, สถานะเป็นข้อความสีตามสถานะ
│ ร้อยละการใช้ยาปฏิชีวนะใน…       │  ← ชื่อ 2 บรรทัด
│ 57.5%  [เคสน้อย · n=1]          │  ← % ใหญ่สีตามสถานะ, ป้ายเฉพาะตัวหาร < 5
│ ▓▓▓▓▓▓▓▓▓▓▓▓│▓▓▓░░░░░░░░░░░    │  ← แถบผลลัพธ์ + ขีดตั้งที่ตำแหน่งเป้า
│ เป้า ≤ 40%      1,032 / 1,794 visit │  ← หน่วยตาม KPI: visit หรือ ผู้ป่วย (KPI08/09/10)
└──────────────────────────────┘
```

- คลิกทั้ง card เพื่อไปหน้า KPI ขอบซ้ายสีตามสถานะ
- KPI ที่ใช้ตัวเลข HDC แทนชั่วคราวมีป้าย "HDC · ทั้งปี" (ตัวเลขทั้งปีงบ ไม่เปลี่ยนตามเดือนที่เลือก)

### เคสน้อย (CONTEXT.md)

ตัวหาร 1–4 → ยังตัดสินสถานะตามปกติและยังอยู่ในแถบ "ต้องดูก่อน" ถ้าไม่ผ่าน แต่ติดป้าย "เคสน้อย · n=X"
ตัวหาร 0 → "ไม่มีข้อมูล" ไม่ใช่เคสน้อย

### เอาออกแล้ว (2026-10-17) และเหตุผล

| ส่วนเดิม | เหตุผล |
|---|---|
| แถบต้อนรับ (คำทักทาย, อัปเดตล่าสุด) | ใช้เวลา UTC ทักทายผิดช่วง และ "อัปเดตล่าสุด" เป็นเวลาที่เปิดหน้า ไม่ใช่เวลาคำนวณ |
| card สรุปตามหมวด "% เฉลี่ย" | เฉลี่ยร้อยละของ KPI ที่ยิ่งต่ำยิ่งดีปนกับยิ่งสูงยิ่งดี ตัวเลขไม่มีความหมาย |
| กราฟเปรียบเทียบผลลัพธ์ vs เป้าหมาย | ซ้ำกับ card, ทิศทางปนกัน, เส้นเป้าลากข้าม KPI ที่ไม่เกี่ยวกัน, KPI ไม่มีข้อมูลถูกวาดเป็น 0 |
| เมนูลัด | 2 ใน 3 เป็นลิงก์ตาย และ "ตั้งค่า HOSxP" ให้ 403 กับผู้ใช้ที่ไม่ใช่ผู้ดูแล |
| ตัวชี้วัดที่ต้องเฝ้าระวัง (กล่อง, สูงสุด 5) | แทนด้วยแถบ "ต้องดูก่อน" ที่แสดงครบทุกตัว |
| ประวัติกิจกรรมล่าสุด | เป็นรหัสภายในของการตั้งค่าผู้ดูแล ไม่เกี่ยวกับงานเภสัช |

## Design Style

- Modern Admin UI — Clean, minimal
- รองรับ Responsive Layout (Desktop-first)
- ใช้ Chart.js สำหรับ Line Chart (Trend), Bar Chart (Comparison)
- สีสถานะ: Green (ผ่าน), Red (ไม่ผ่าน), Yellow (ใกล้เป้าหมาย ±5%)
- Sidebar แสดง Badge สีสถานะแต่ละ KPI
- Skeleton loading สำหรับ KPI Cards
