Prerequisites

ติดตั้ง software ครบก่อนเริ่มขั้นตอนต่อไป

terminal ตรวจ version ครบด้วย: php -v && composer -V && node -v && git --version && psql --version

Clone จาก GitHub

ดึงโค้ดจาก private repository nuttapong39/RDU

เปิด PowerShell แล้วรัน:

cd C:\xampp\htdocs
git clone https://github.com/nuttapong39/RDU.git
cd RDU
info
ถ้าถาม username/password: ใช้ GitHub username + Personal Access Token (สร้างที่ github.com/settings/tokens scope repo)

ติดตั้ง PHP Dependencies

Composer จะดาวน์โหลด Laravel + package ทั้งหมด (~120 MB)

composer install --optimize-autoloader --no-dev
💡 --no-dev = production mode (ไม่ติดตั้ง phpunit) — ถ้าจะรัน test ใช้ composer install เฉย ๆ

Build Frontend Assets

NPM ติดตั้ง + Vite compile Tailwind + JS bundle

npm ci
npm run build
จะได้ public/build/assets/app-*.css + app-*.js ที่ Blade ใช้ผ่าน @vite

ตั้งค่า .env

Copy template + generate app key + แก้ 4 บรรทัด

copy .env.example .env
php artisan key:generate
notepad .env

แก้ 4 ค่าใน .env:

APP_ENV=production
APP_DEBUG=false
APP_URL=http://192.168.1.XX
DB_PASSWORD=your_postgres_password

สร้าง Database + Migrate

สร้าง rdu_dashboard DB + สร้าง table + seed admin user

& "C:\Program Files\PostgreSQL\18\bin\psql.exe" -U postgres -c "CREATE DATABASE rdu_dashboard;"

php artisan migrate --seed
check_circle
Seed จะสร้าง user admin/admin + 13 KPI indicators พร้อมใช้งาน

ผ่าน Admin UI (แนะนำ) — encrypt password อัตโนมัติ

  1. เริ่ม server: php artisan serve --host=0.0.0.0 --port=8000
  2. เปิด browser: http://localhost:8000
  3. Login: admin / admin
  4. คลิก ตั้งค่าฐานข้อมูล HOSxP ใน sidebar
  5. กรอกค่าตามตาราง (สอบถามจาก IT ของโรงพยาบาล):

ตั้งค่า Apache (XAMPP)

Point DocumentRoot ไป public/ — สำคัญเรื่อง security

แก้ C:\xampp\apache\conf\extra\httpd-vhosts.conf:

<VirtualHost *:80>
    ServerName rdu.local
    DocumentRoot "C:/xampp/htdocs/RDU/public"

    <Directory "C:/xampp/htdocs/RDU/public">
        Options Indexes FollowSymLinks
        AllowOverride All
        Require all granted
    </Directory>

    ErrorLog "logs/rdu-error.log"
    CustomLog "logs/rdu-access.log" common
</VirtualHost>

เพิ่มใน C:\Windows\System32\drivers\etc\hosts:

127.0.0.1  rdu.local

Restart Apache ผ่าน XAMPP Control Panel

Troubleshooting

ปัญหาที่พบบ่อย + วิธีแก้

chevron_right error could not find driver

PHP ยังไม่เปิด pdo_pgsql extension

แก้: เปิด C:\xampp\php\php.ini ค้นหา extension=pdo_pgsql แล้วเอา ; ด้านหน้าออก → restart Apache

chevron_right error password authentication failed for user "rdu_readonly"

JSON config ผิด หรือ user บน HOSxP ไม่มี/password ผิด

แก้: ไปที่ ตั้งค่าฐานข้อมูล HOSxP → กรอกใหม่ → Test Connection

chevron_right error database "chk_hosxe" does not exist

ชื่อ database ใน JSON ผิด — ต้องตรงกับที่ HOSxP admin ตั้งไว้

แก้: สอบถามจาก IT โรงพยาบาล → แก้ใน UI

chevron_right error relation "ovst" does not exist

rdu_readonly ไม่มี USAGE บน schema หรือ views ยังไม่ได้สร้าง

แก้: SSH เข้า HOSxP server แล้ว:

GRANT USAGE ON SCHEMA rdu_kpi TO rdu_readonly;
GRANT SELECT ON ALL TABLES IN SCHEMA rdu_kpi TO rdu_readonly;
chevron_right warning Icons/fonts ไม่โหลด (empty box)

เครื่อง target ไม่มีอินเทอร์เน็ต → โหลด Google Fonts + Material Symbols ไม่ได้ — ต้องดาวน์โหลด fonts มาเก็บ local (ดู docs/ ภายหลัง)

chevron_right warning git pull conflict

Reset local ให้ตรงกับ remote (ทิ้งการแก้ในเครื่อง — ยกเว้น .env/rdu_database.json ที่ ignored):

git fetch origin
git reset --hard origin/main
